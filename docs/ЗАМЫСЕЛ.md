во всех вёрстках и со всеми картинками. На Tilda ничего не сажать, только брать оттуда. На GitHub

**Путь (этап 1 — копия).**
1. Список страниц: sitemap сайта и потоков + страницы проекта Tilda; без карточек товаров.
2. Скачать HTML каждой страницы как её отдаёт teyes-sibir.ru.
3. Собрать все ресурсы: стили, скрипты, шрифты, картинки (включая ленивую подгрузку и фоны);
   картинки — в WebP без видимой разницы, чтобы сайт влез в лимит GitHub Pages 1 ГБ.
4. Собрать `public/`: те же страницы, ссылки между ними — внутри копии, ресурсы — локальные,
   повторяющиеся стили и скрипты — общими файлами, без счётчиков, закрыто от поиска.
5. Проверить: каждая страница открывается, ничего не тянется с CDN Tilda (кроме магазина и форм),
   скриншоты копии совпадают с живым сайтом.
